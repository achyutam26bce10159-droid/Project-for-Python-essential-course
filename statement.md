Project Statement

1. Problem Statement

Managing products manually is become difficult when the number of products increases. Keeping track of product names, quantities, prices, sales, and deleted products using manual records often lead to errors and make inventory management less efficient.

This system allows users to add, view, search, update, sell, and delete products through a command-line interface.

The project aims to demonstrate how basic Python programming concepts can be applied to solve a practical inventory management problem.

---

2. Scope of the Project

The scope of this project is to provide basic inventory management functionality through a console-based Python application.

The system covers the following activities:

- Adding new products to the inventory.
- Viewing all available products.
- Searching for a product using its index.
- Updating product information.
- Selling a product and reducing its quantity.
- Deleting products from the inventory.
- Exiting the application through a menu option.

The current version is designed for basic and small-scale inventory management. 
Product information is stored temporarily in the program's memory and is not saved permanently after the application is closed.

___________________

3. Target Users

The project is primarily intended for:

Students

Students can use the project to understand how Python programming concepts can be applied to a real-world problem.

Small-Scale Sellers

Small shop owners or individual sellers can use a similar system to keep track of a limited number of products.

Beginners Learning Python

The project can serve as an example for learners who are studying:

- Functions
- Dictionaries
- Loops
- Conditional statements
- User input
- Basic data management
- CRUD operations

Academic Use

The project is suitable for educational demonstrations, Python programming assignments, and introductory programming coursework.
